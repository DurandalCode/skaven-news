# Ведение выпуска

Корень проекта — каталог с `AGENTS.md` над `.agents/skills`. Все пути ниже относительно корня проекта.

1. Прочитай `editorial/channel.md` и `editorial/workflow.md`. Для существующего выпуска прочитай его состояние и последние материалы.
2. Новую папку выпуска создавай после получения новости от пользователя. Самостоятельный поиск повестки в задачу не входит.
3. Для фактической основы и текста используй инструкции соседнего `wfb-news-adapt/SKILL.md`; для изображения — `wfb-art-direct/SKILL.md`; для предпросмотра — `wfb-telegram/SKILL.md`. Это этапы одной работы, а не поручение запускать отдельных агентов.
4. Показывай на каждом утверждении конкретный результат и коротко указывай, что именно утверждается. Не объединяй три решения молча.
5. Записывай решения и версии по правилам процесса. Продолжай с первого незавершённого этапа, учитывая новые указания пользователя.

Если пользователь прислал примеры, прочитай `editorial/examples.md` и тематические документы. Извлеки из примеров предложения по правилам, покажи их пользователю; только подтверждённые решения записывай как утверждённые. Не запускать выпуск, если пользователь прислал только референсы.

При отсутствии доступа к источнику или Telegram выполняй доступную подготовку и явно называй ограничение. Не отмечай недоступное действие как выполненное.
