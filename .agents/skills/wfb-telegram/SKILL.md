# Подготовка и публикация

Пути ниже относительно корня проекта с `AGENTS.md`. Прочитай `editorial/workflow.md`, `editorial/writing-style.md` и состояние выпуска.

## Подготовить

Просьбы «сделай пост», «подготовь» и «сверстай» означают подготовку. Собери точные текст и изображение, сохрани текстовую разметку в `telegram.html` и покажи читаемый предпросмотр. Не вставляй служебные пояснения в сообщение.

Перед подготовкой под реальную отправку проверь актуальные требования выбранного интерфейса Telegram по официальной документации: длину текста и подписи, разметку, тип и размер вложений. Не считай произвольный HTML поддерживаемым Telegram.

Если комплект не помещается в одно сообщение, предложи конкретное разделение и покажи весь порядок сообщений для финального согласования. Не сокращай текст после утверждения без обновления предпросмотра.

## Опубликовать

В исходной версии проекта отправка не настроена. Не имитируй её и не проси вставлять токен в чат. Подготовь комплект для ручной публикации. Реализацию подключения выполняй только по отдельному поручению.

Когда доступ настроен, перед отправкой проверь:

- есть явная команда пользователя на публикацию показанного комплекта;
- известны целевой канал и порядок сообщений;
- контрольные суммы отправляемых файлов совпадают с утверждёнными;
- этот выпуск ещё не опубликован и не находится в `delivery_unknown`.

Отправь только утверждённый комплект. Сохрани ответ сервиса и идентификаторы без секретов по `workflow.md`. При неопределённом результате не повторяй отправку автоматически. Планирование, удаление и редактирование существующих сообщений не входят в команду на подготовку нового поста.
