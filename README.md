# Скавенские новости

Небольшая редакция сатирических новостей в мире Warhammer Fantasy Battles. Пользователь выбирает повестку, агент помогает придумать адаптацию и подготовить пост для Telegram.

## Как работать

Открой этот репозиторий в Codex и пришли выбранную новость: текст, ссылку или заведомо вымышленный сатирический повод. Агент читает `AGENTS.md`, предлагает адаптацию и сохраняет материалы выпуска. Текст для копирования готовится в Telegram HTML, отдельно от редакционных пояснений.

Работа строится вокруг конкретных выпусков: обсуждаем шутку, правим текст, сохраняем удачные образцы и уточняем правила. Для перехода к иллюстрации и публикации действуют [этапы утверждения](editorial/workflow.md). Прямые поручения пользователя учитываются без повторных вопросов.

## Что где лежит

| Путь | Содержимое |
| --- | --- |
| `AGENTS.md` | Входные инструкции агенту |
| `editorial/` | Перспектива редакции, лор, соответствия, речь, стиль и процесс |
| `editorial/examples/2023-2024.md` | Исходные авторские примеры |

| `references/` | Ссылки и авторство художественных референсов |

## Принятые ориентиры

- Скавенская перспектива; Подземная Империя — постсоветское пространство.
- Остальные соответствия гибкие, под конкретную шутку. Новую постоянную пару не закрепляем без решения пользователя.
- Старые тексты — материал для настройки, а не обязательный шаблон каждой новости.
- Посты сразу готовим под Telegram. Вымышленность исходника фиксируем в рабочих материалах.
- Генерацию иллюстраций строим вокруг Nano Banana. Сейчас пользователь генерирует через зеркало; редактирование готовых картинок в нём работает плохо. Подробности — в [правилах иллюстраций](editorial/art-style.md#генератор-и-рабочий-процесс).
